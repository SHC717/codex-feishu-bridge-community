
# Windows 原生环境检查

这是飞书桥安装、环境预检和部署状态检查所需的本地模块，随 community 仓库完整提供。它检查当前用户、官方程序所在路径和 Windows 原生执行环境，不读取账号凭据，不注册任务，不修改系统设置。

`WindowsNative.psm1` 是运行模块；`Test-WindowsNativeContext.ps1` 是只读命令行入口；`WindowsNative.Tests.ps1` 使用合成数据和本机只读身份/路径查询核对拒绝边界。

安装器从仓库内相邻目录引用本模块，并将需要的运行文件复制到安装者自己的运行目录。缺失、重定向或身份不符时停止，不自动下载替代模块，也不降低检查。
