# Codex 飞书桥 · Community

**让 Codex 的问题和结果，主动到手机上找你。**

飞书桥是 Windows 上的常驻辅助程序。它把本机 Codex 各项目已加载任务的待回答问题、待处理提醒和最终结果发送到手机飞书；支持的普通选择题和文字补充可以在手机回答，答案回到电脑上的原任务。

当前共享版本为 **1.3.1-community.1**，桥接核心版本为 **1.3.1**。本仓库已公开，只包含飞书桥及其必要的 Windows 环境检查模块，使用独立提交历史。

## 适合什么场景

- **任务正在等你回答。** 普通选项和文字补充进入「Codex 交互请求」，手机收到后可作答。
- **不想反复打开远控界面等连接。** 问题和结果走飞书通知通道，不要求手机一直停留在远控页面。
- **人离开电脑，任务继续运行。** 电脑后台保持桥接；最终答复和失败/中断状态进入「Codex 结果通知」，长文按需分页或作为附件发送。

命令、文件、权限审批及原生 Plan 提问目前仅发送提醒，仍需在电脑处理。桥接不修复 VPN 或底层网络故障。电脑须开机、联网且 Codex 可连接；手机弹窗还取决于飞书和系统通知设置。睡眠、关机或服务不可达时不能即时发送。

## 第一次使用

1. 使用 Git 克隆到本机普通、非同步目录，或点击 **Code → Download ZIP** 并完整解压。完整仓库包含必要依赖。
2. 阅读 [安装与更新说明](codex-feishu-bridge/README.md)，先完成只读环境检查，再在自己的电脑安装。
3. 使用自己的 Codex、飞书应用/机器人和本机 CLI profile。应用密钥只交给自己电脑上的官方 CLI 安全输入入口。
4. 安装后在自己的手机完成文字、按钮、结果通知和暂停/恢复验证。

```powershell
git clone https://github.com/SHC717/codex-feishu-bridge-community.git
cd codex-feishu-bridge-community\codex-feishu-bridge
```

浏览和下载不需要协作者邀请。已有克隆可在检查本地修改后获取后续更新；源码更新和已安装程序更新是两个步骤，具体见安装说明。

## 电脑要求

Windows x64；当前用户安装的官方 Codex Windows 应用；Node.js 22+；Python 3.12+（Python 3）；PowerShell 7.x；当前代码核验的飞书 CLI 1.0.93。代码没有 npm 依赖，不会自动安装或升级这些环境。已有环境可以通过安装参数明确指定路径。

手机端使用飞书即可，电脑端飞书客户端可以关闭。此项目由社区独立维护，与 OpenAI、飞书官方无隶属关系。

## 使用与数据

桥接会把本机各项目已加载用户任务的问题和最终答复发送到安装者自己配置的飞书私有群。安装前应确认这个范围符合自己的使用需求。本地文件和图片链接不会自动读取或上传。

消息格式转换在本机完成，不额外调用模型；手机回答后 Codex 原任务继续运行时，按该任务正常使用模型额度。

每台电脑独立配置。不要复制其他人的密钥、CLI 凭据、部署配置、消息记录或数据库，也不要把这些文件提交到仓库。共享版与自用版使用同一默认运行目录，不能当成两个独立实例并行安装；已有安装按更新流程处理。
