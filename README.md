
# Codex Feishu Bridge Community

这是飞书桥的独立私有共享版，面向 Windows x64 用户。它把本机 Codex 已加载任务的待回答问题和最终结果发送到手机飞书；普通选择题和文字补充可以在手机回答，答案回到电脑上的原任务。

当前共享版本为 **1.3.1-community.1**，桥接核心版本为 **1.3.1**。新仓库只包含飞书桥及其必要的 Windows 环境检查模块，采用独立提交历史。共享版与维护者的自用仓库分别管理。

## 第一次使用

1. 接受仓库协作者邀请，再登录 GitHub 打开本仓库。私有仓库链接本身不授予访问权限。
2. 使用 Git 克隆到本机普通、非同步目录，或点击 **Code → Download ZIP** 并完整解压。只下载某一个子文件夹会漏掉依赖。
3. 阅读 [安装与更新说明](codex-feishu-bridge/README.md)，先完成只读环境检查，再在自己的电脑安装。
4. 使用自己的 Codex、飞书应用/机器人和本机 CLI profile。应用密钥只交给自己电脑上的官方 CLI 安全输入入口。
5. 安装后在自己的手机完成文字、按钮、结果通知和暂停/恢复验证。

```powershell
git clone https://github.com/SHC717/codex-feishu-bridge-community.git
cd codex-feishu-bridge-community\codex-feishu-bridge
```

已有克隆可在检查本地修改后获取后续更新；源码更新和已安装程序更新是两个步骤，具体见安装说明。尚未获邀或尚未接受邀请时，看到 404 不代表仓库不存在。

## 电脑要求

Windows x64；当前用户安装的官方 Codex Windows 应用；Node.js 22+；Python 3.12+（Python 3）；PowerShell 7.x；当前代码核验的飞书 CLI 1.0.93。代码没有 npm 依赖，不会自动安装或升级这些环境。已有环境可以通过安装参数明确指定路径。

手机端使用飞书即可，电脑端飞书客户端可以关闭。电脑仍需开机、联网且 Codex 可连接。命令、文件、权限等审批只会提醒，仍需在电脑处理。

## 使用与数据

消息包括普通通知、两个分类会话、完整最终答复和长文附件。格式转换在本机完成，不额外调用模型；手机回答后 Codex 原任务继续运行时，按该任务正常使用模型额度。

桥接会把本机各项目已加载用户任务的问题和最终答复发送到安装者自己配置的飞书私有群。安装前应确认这个范围符合自己的使用需求。本地文件和图片链接不会自动读取或上传。

每台电脑独立配置。不要复制其他人的密钥、CLI 凭据、部署配置、消息记录或数据库，也不要把这些文件提交到仓库。共享版与自用版使用同一默认运行目录，不能当成两个独立实例并行安装；已有安装按更新流程处理。

## 后续维护

受邀协作者在这个仓库具有读写权限，可提交自己的修改。源码的存在、测试通过和朋友电脑上的真实使用通过分别记录。维护者的自用程序不会因为本仓库更新而自动改变。
